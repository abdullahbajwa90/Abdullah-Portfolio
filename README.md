## 🌐 How to Host on GitHub Pages (Step-by-Step)

Follow these simple steps to make your portfolio live on `yourusername.github.io`:

### Step 1: Initialize Git and Create a Repository
Open your terminal in this directory (`f:\AntiGravity-Projetcs`) and run:
```bash
git init
git add .
git commit -m "Initial release of Abdullah Bajwa portfolio"
```

### Step 2: Push to GitHub
1. Go to [GitHub.com](https://github.com) and click **New Repository**.
2. Name it something like `portfolio` or `abdullahbajwa.github.io`.
3. Set it to **Public**.
4. Run:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. In your GitHub repository, click on **Settings** (top tab).
2. On the left sidebar, click on **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your website will be live at:
   `https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/`
